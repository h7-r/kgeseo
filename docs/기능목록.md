# 『왜곡』 12월 범위 기능 목록 — 진행표

PRD v1.8 시트를 그대로 옮긴 것. **하나도 빠뜨리지 않기 위한 원본 대조표**다.
상태: ⬜ 안 함 · 🟨 진행 중 · ✅ 완료 · ⏸ 대기(팀원 자산/서버 필요) · ⛔ 12월 제외

> 이 프로젝트에서 **내가 지금 할 수 있는 것 = FE**.
> 서버 판정(BE)은 팀원 몫이라 `src/서버/api.js` 인터페이스만 맞춰 두고 로컬 모의로 돌린다.
> 아바타 파츠(24종 GLB)는 팀원이 전달하면 진행한다.
> **웹페이지(S0 랜딩 · S1 계정/동의 · 마이페이지 · FAQ)는 사용자가 피그마로 직접 작업 중** → 내 범위 밖.
