# Meshy 캐릭터를 R3F 게임 캐릭터로 만드는 순서

Meshy에서 받은 고해상도 메쉬는 **컨셉/외형 원본**으로 두고, 게임에서 움직일 본체는 별도로 만든다. 바로 리그를 넣고 자동 웨이트를 적용하면 어깨·사타구니처럼 붙어 있는 부위가 늘어나거나 찢어진다.

## 0. 원본 보관

- Meshy에서 GLB 또는 FBX를 내려받는다.
- Blender에서 즉시 `character_source.blend`로 저장한다.
- 원본에는 리메시·리그·웨이트를 적용하지 않는다.

## 1. 게임용 메쉬 만들기

목표는 팔꿈치, 무릎, 어깨, 사타구니에 고르게 도는 사각형(quad) 면 흐름이다.

1. 원본을 복제해 `character_game.blend`에서 작업한다.
2. 겹친 내부 면, 분리된 작은 파편, 비정상 노멀을 정리한다.
3. 수작업 리토폴로지로 몸통·팔·다리·얼굴의 면을 다시 만든다.
4. 어깨는 팔 둘레로 3개 이상의 고리(edge loop)를 둔다.
5. 팔과 몸통이 하나의 표면이어도 괜찮다. 단, 관절 주변의 면이 팔 둘레를 따라 돌아야 한다.
6. 새 메쉬를 원본에 Shrinkwrap해서 실루엣을 맞춘다.

자동 리메시가 외형을 망기거나 쿼드화를 거부하면 그 자동 결과를 게임 본체로 쓰지 않는다. 이때는 새 게임용 메쉬를 직접 만드는 편이 더 빠르고 안정적이다.

## 2. 디테일 복원

1. 게임용 메쉬 UV를 편다.
2. 원본의 노멀·베이스컬러·AO를 게임용 UV로 베이크한다.
3. 눈·머리·옷처럼 독립적으로 움직이지 않아도 되는 파트는 별도 메쉬로 유지해도 된다.

## 3. 리깅

1. 게임용 메쉬와 Armature의 위치·회전·스케일을 적용한다. (`Ctrl+A` → Rotation & Scale)
2. 리그의 휴식 자세(Rest Pose)가 캐릭터의 A-pose/T-pose와 맞는지 정면·측면에서 확인한다.
3. 메쉬 선택 → Shift로 리그 선택 → `Ctrl+P` → With Automatic Weights.
4. Weight Paint에서 어깨·팔꿈치·사타구니·무릎을 정리한다.
5. 각 버텍스의 가중치는 총합 1.0, 영향 본 수는 보통 4개 이하로 제한한다.

## 4. 필수 변형 테스트

포즈 모드에서 아래를 순서대로 검사한다.

- 팔을 앞·옆·위로 45도, 90도 들기
- 팔꿈치 90도 굽히기
- 다리 45도 앞으로 들기, 무릎 90도 굽히기
- 상체 30도 돌리기
- 걷기 자세처럼 반대 팔·다리를 동시에 움직이기

테스트 중 몸통이 팔을 따라가거나 표면이 풍선처럼 늘어나면 애니메이션을 만들지 말고 그 관절의 토폴로지/가중치를 먼저 고친다.

## 5. 애니메이션과 내보내기

1. Idle, Walk, Run 같은 액션을 만든다.
2. 제어 리그(Rigify)를 사용했다면 변형 뼈(DEF bones)에 액션을 베이크한다.
3. `glTF 2.0`으로 GLB를 내보낸다.
4. 내보내기 옵션: Selected Objects, Apply Modifiers, Animations, Skinning을 켠다.
5. GLB를 Blender에서 다시 열어 애니메이션이 재생되는지 확인한다.

## 6. R3F 적용

- 파일 위치: `public/models/character.glb`
- 로딩: Drei의 `useGLTF`
- 재생: Drei의 `useAnimations`
- 캐릭터는 한 번만 로딩하고 여러 인스턴스가 필요할 때는 SkeletonUtils clone을 사용한다.

검증된 GLB가 나온 뒤에만 게임 씬에 넣는다.
