# 브랜치 · 작업 규칙

여섯 명이 한 저장소를 쓰기 때문에, 규칙 없이 하면 **머지 충돌 정리하는 데 개발 시간보다 더 든다.**
아래는 최소한의 약속이다.

---

## 1. 브랜치

```
main                     항상 돌아가는 상태. 여기에 직접 푸시하지 않는다.
├── feat/랑-기차내부       새 기능
├── fix/문통과안됨         버그 수정
└── docs/기획서정리        문서
```

**이름 규칙** — `종류/이름-무엇`

| 종류 | 언제 |
|---|---|
| `feat/` | 새 기능·새 씬·새 물건 |
| `fix/` | 버그 |
| `docs/` | 문서·기획서 |
| `chore/` | 설정·패키지·정리 |

## 2. 작업 흐름

```bash
# ① 최신 main 을 받아온다 (항상 여기서 시작)
git switch main
git pull

# ② 브랜치를 딴다
git switch -c feat/내이름-작업내용

# ③ 작업하고 커밋 (자주, 작게)
git add .
git commit -m "기차 내부 좌석 배치"

# ④ 올린다
git push -u origin feat/내이름-작업내용

# ⑤ GitHub 에서 Pull Request 를 만든다 → 리뷰 → main 에 머지
```

**중요** — 작업이 길어지면 중간중간 main 을 가져와 섞는다. 안 그러면 나중에 충돌이 산더미가 된다.

```bash
git switch main && git pull
git switch feat/내브랜치
git merge main
```

## 3. ★ 이 프로젝트에서 제일 중요한 규칙 — 한 파일에 한 사람

`src/App.jsx` 는 **1만 줄이 넘는다.** 두 사람이 동시에 손대면 충돌이 반드시 난다.
그리고 3D 씬 코드는 충돌이 나면 어느 쪽이 맞는지 눈으로 판단하기가 거의 불가능하다.

**그래서 파일 단위로 나눠 맡는다.**

| 파일 | 담당 |
|---|---|
| `src/App.jsx` | 역(승강장·복도) 씬 — 한 명 |
| `src/scenes/기차내부.jsx` | 기차 안 — 한 명 |
| `src/공용.jsx` | **아무나 손대지 않는다.** 바꿀 일이 생기면 먼저 팀에 말한다 |

새 공간을 만들 때는 **`src/scenes/` 아래 새 파일**로 만든다. App.jsx 에 이어 붙이지 않는다.

## 4. 커밋 메시지

한글로, **무엇을 했는지** 한 줄. 왜 했는지는 필요하면 아래 줄에.

```
기차 내부 좌석 7열 배치

통로 폭이 좁아서 좌석 간격을 6.2 → 6.8 로 넓혔다.
```

`수정`, `ㅇㅇ`, `asdf` 같은 메시지는 나중에 아무도 못 찾는다.

## 5. 커밋에 넣지 않는 것

`.gitignore` 가 대부분 막아 주지만, 사람이 조심해야 하는 것도 있다.

- **`node_modules/`** — 289MB. 절대 올리지 않는다. `npm install` 로 복원된다.
- **`dist/`** — 빌드 결과물. 소스에서 다시 만들어진다.
- **손으로 만든 백업 파일** (`App.backup*.jsx`) — 이제 깃이 그 일을 한다.

## 6. Leva 값에 대해 — 헷갈리기 쉬운 부분

Leva 패널에서 조절한 값은 **내 브라우저에만 저장된다**(localStorage).
**커밋해도 팀원에게 전달되지 않는다.**

값을 확정하려면 **코드의 기본값에 직접 박아야** 한다.

```js
배관x비율: { value: 0.62, ... }   // ← 이 숫자를 바꿔서 커밋해야 공유된다
```

"내 화면에선 되는데 팀원 화면에선 다르다" 의 90%가 이것이다.

## 7. 충돌이 났을 때

당황해서 `--force` 로 밀어 버리면 남의 작업이 사라진다. **절대 하지 않는다.**

```bash
git status              # 어떤 파일이 충돌했는지 본다
# 파일을 열어 <<<<<<< ======= >>>>>>> 사이를 직접 정리한다
git add <정리한 파일>
git commit
```

혼자 판단이 안 서면 **정리하기 전에 팀에 물어본다.** 3D 씬 코드는 특히 그렇다.
