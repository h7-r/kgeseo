## 4. 편집 방법 (Higgsfield 샌드박스에서)

편집·합성은 Higgsfield `sandbox_exec` (ffmpeg 내장) 에서 했다. **샌드박스는 시간이 지나면 초기화되니** 아래 스크립트를 다시 써서 돌린다.

### 규칙 (v2 기준, 사용자 OK)

- 컷 하나 = 그 컷에 배정된 대사 길이에 **딱 맞춘다**. 대사 앞 0.15초, 같은 컷 안의 대사 사이 0.2초, 대사 뒤 0.2초. 첫 컷만 앞에 0.15초 더.
- 화면이 대사보다 **길면** 최대 1.5배 빠르게 돌리고, 그래도 길면 **앞부분을** 자른다 (마무리 동작은 대개 끝에 있음).
- 화면이 대사보다 **짧으면** 최대 1.35배 느리게, 그래도 모자라면 마지막 프레임 정지.
- 마지막 타이틀(14)은 속도 그대로 두고 대사 뒤 1초 여운.
- 컷 효과음은 볼륨 0.28 로 깔고 내레이션은 그대로. 최종 `loudnorm I=-16`.
- 자막: `Noto Sans CJK KR` Bold, 56px, 흰 글씨 + 검은 테두리 3.5, 하단 여백 64 (1920×1080 기준). 대사 시작~끝+0.15초 동안 표시.
- 한글 폰트는 샌드박스에 없어서 받아야 한다:
  `curl -sfL -o ~/.fonts/NotoSansCJKkr-Bold.otf https://github.com/notofonts/noto-cjk/raw/main/Sans/OTF/Korean/NotoSansCJKkr-Bold.otf && fc-cache -f`

### 스크립트 (`~/wg/final/build.py`)

준비물: `~/wg/v/01.mp4 … 14.mp4, 08b.mp4` (위 컷 표의 영상), `~/wg/vo_zip/audio_<번호>_*.wav` (내레이션 zip 압축 해제).

```python
import glob, subprocess, os
V=os.path.expanduser("~/wg/v"); A=os.path.expanduser("~/wg/vo_zip"); O=os.path.expanduser("~/wg/final")
def dur(f): return float(subprocess.check_output(["ffprobe","-v","error","-show_entries","format=duration","-of","csv=p=0",f]).decode())
def voice(i): return glob.glob(f"{A}/audio_{i}_*.wav")[0]
TXT={}  # ← 2절의 대사 표 0~16 을 그대로 넣는다 (줄바꿈은 "\\N")
SEG=[("01",[0]),("02",[1]),("03",[2]),("04",[3,4]),("05",[5]),("06",[6,7]),("07",[8]),("08",[9]),
     ("08b",[10]),("09",[11]),("10",[12]),("11",[13]),("12",[14]),("13",[15]),("14",[16])]
LEAD,GAP,TAIL=0.15,0.2,0.2
events=[]; t0=0.0; parts=[]
for k,(clip,lines) in enumerate(SEG):
    cf=f"{V}/{clip}.mp4"; cd=dur(cf); vd=[dur(voice(i)) for i in lines]
    need=LEAD+sum(vd)+GAP*(len(lines)-1)+TAIL
    if k==0: need+=0.15
    if clip=="14": need+=1.0
    L=need
    if clip=="14": f=1.0
    elif cd>L: f=max(L/cd,1/1.5)
    else: f=min(L/cd,1.35)
    pad=max(0.0,L-cd*f); cut=max(0.0,cd*f-L)
    vf=f"setpts={f}*PTS,trim=start={cut:.3f},setpts=PTS-STARTPTS,tpad=stop_mode=clone:stop_duration={pad:.3f},trim=duration={L:.3f},fps=24,format=yuv420p"
    af=f"[0:a]aresample=48000,atempo={1/f:.4f},atrim=start={cut:.3f},asetpts=PTS-STARTPTS,apad,atrim=duration={L:.3f},volume=0.28[s]"
    inputs=["-i",cf]; mix=["[s]"]; t=LEAD+(0.15 if k==0 else 0)
    for j,i in enumerate(lines):
        inputs+=["-i",voice(i)]; ms=int(t*1000)
        af+=f";[{j+1}:a]aresample=48000,pan=stereo|c0=c0|c1=c0,adelay={ms}|{ms},apad,atrim=duration={L:.3f}[v{j}]"; mix.append(f"[v{j}]")
        events.append((t0+t, t0+t+vd[j]+0.15, TXT[i])); t+=vd[j]+GAP
    af+=f";{''.join(mix)}amix=inputs={len(mix)}:normalize=0:duration=first[a]"
    out=f"{O}/seg{k:02d}.mp4"
    subprocess.check_call(["ffmpeg","-v","error","-y",*inputs,"-filter_complex",f"[0:v]{vf}[vv];{af}","-map","[vv]","-map","[a]",
        "-c:v","libx264","-preset","veryfast","-crf","18","-c:a","aac","-b:a","192k","-ar","48000","-t",f"{L:.3f}",out])
    parts.append(out); t0+=dur(out)
open(f"{O}/list.txt","w").write("".join(f"file '{p}'\n" for p in parts))
def ts(x): return f"{int(x//3600)}:{int(x%3600//60):02d}:{x%60:05.2f}"
ass="""[Script Info]
ScriptType: v4.00+
PlayResX: 1920
PlayResY: 1080
WrapStyle: 2

[V4+ Styles]
Format: Name, Fontname, Fontsize, PrimaryColour, SecondaryColour, OutlineColour, BackColour, Bold, Italic, Underline, StrikeOut, ScaleX, ScaleY, Spacing, Angle, BorderStyle, Outline, Shadow, Alignment, MarginL, MarginR, MarginV, Encoding
Style: Default,Noto Sans CJK KR,56,&H00FFFFFF,&H00FFFFFF,&H00000000,&H80000000,-1,0,0,0,100,100,0,0,1,3.5,1.5,2,120,120,64,1

[Events]
Format: Layer, Start, End, Style, Name, MarginL, MarginR, MarginV, Effect, Text
"""
for s,e,tx in events: ass+=f"Dialogue: 0,{ts(s)},{ts(e)},Default,,0,0,0,,{tx}\n"
open(f"{O}/subs.ass","w").write(ass)
subprocess.check_call(["ffmpeg","-v","error","-y","-f","concat","-safe","0","-i",f"{O}/list.txt","-c","copy",f"{O}/clean.mp4"])
subprocess.check_call(["ffmpeg","-v","error","-y","-i",f"{O}/clean.mp4","-vf",f"ass={O}/subs.ass","-af","loudnorm=I=-16:TP=-1.5:LRA=11",
    "-c:v","libx264","-preset","veryfast","-crf","19","-pix_fmt","yuv420p","-c:a","aac","-b:a","192k","-ar","48000",
    "-movflags","+faststart",f"{O}/waegok_intro_v2.mp4"])
```

실행은 오래 걸리니 `sandbox_exec` 에 `background: true, size: "xl"` 로 돌리고 로그를 폴링한다.
결과 업로드: `media_upload` 로 업로드 URL 을 먼저 받고 → 같은 샌드박스 명령에서 `curl -X PUT -H "Content-Type: video/mp4" -H "If-None-Match: *" --upload-file …` → HTTP 200 확인 후 `media_confirm`.
확인: 자막이 들어간 프레임을 뽑아 `image_paths` 로 눈으로 본다 (512KB 이하로 줄여서).

## 5. 다음 할 일 — Typecast API 연결

사용자가 Typecast API 키를 갖고 있고, 클라우드 환경 설정을 이미 바꿨다 (2026-11-03).

| 설정 | 상태 |
|---|---|
| 환경 변수 `TYPECAST_API_KEY` | 사용자가 등록함. **새 세션부터 적용** → 새 세션에서 `[ -n "$TYPECAST_API_KEY" ]` 로 먼저 확인 |
| 허용 도메인 | `*.typecast.ai`, `typecast.ai`, `upload.higgsfield.ai`, `*.cloudfront.net` 추가 확인됨 (접속 테스트 통과) |

### 연결 확인 결과 (2026-11-03)

| 항목 | 결과 |
|---|---|
| `TYPECAST_API_KEY` 환경 변수 | ✅ 들어옴 |
| API 주소 · 인증 | `https://api.typecast.ai` · 헤더 `X-API-KEY: <키>` |
| 목소리 목록 `GET /v2/voices` | ✅ 200 — 631개 (모델 `ssfm-v31` / `v30` / `v21`, 감정 normal·happy·sad·angry·whisper·toneup·tonedown) |
| 구독 정보 `GET /v1/users/me/subscription` | ✅ 200 — **free 플랜**, 크레딧 15,000 중 0 사용, 동시 요청 2 |
| 음성 생성 `POST /v1/text-to-speech` | ❌ **403 `UNUSUAL_ACTIVITY_DETECTED`** — 무료 계정을 클라우드 서버(데이터센터 IP)에서 호출해서 막힌 것으로 보인다. 키 문제는 아님 |

→ 클라우드에서 음성을 자동 생성하려면 **Typecast 유료 API 플랜**이 필요할 가능성이 크다. 그 전까지는 사용자가 Typecast 웹에서 녹음해 Higgsfield 프로젝트에 올려 주는 기존 방식으로 간다.
→ 403 이 난 뒤 **같은 요청을 반복하지 않는다** (무료 계정 정지 경고가 함께 왔다).

TTS 요청 형식 (확인용):
```json
POST /v1/text-to-speech
{"voice_id":"tc_…","text":"…","model":"ssfm-v31","language":"kor",
 "prompt":{"emotion_preset":"normal"},"output":{"audio_format":"wav"}}
```

**새 세션이 할 일**
1. 키가 들어왔는지 확인. 없으면 사용자에게 「클라우드 환경 편집 → 환경 변수」에 `TYPECAST_API_KEY=키` 저장 여부를 다시 확인해 달라고 한다. **키를 채팅에 붙여 넣게 하지 않는다.**
2. Typecast API 문서를 확인한다 (MCP 서버: `neosapience/typecast-api-mcp-server`, 공식 문서 `https://typecast.ai/docs`). 목소리 목록·TTS·**타임스탬프 TTS**(단어별 시간 → 자막 싱크에 유용)가 있다. API 주소·인증 헤더는 문서에서 확인할 것 (이 가이드 작성 시점엔 확인하지 못했다).
3. 사용자에게 **이번에 쓴 목소리 이름(캐릭터)·속도·감정 설정**을 물어서 같은 목소리로 생성한다.
4. 만든 음성을 Higgsfield 샌드박스로 옮겨(업로드 → URL) 4절 방식대로 합성.

## 7. 지켜야 할 것

- **캐릭터는 얼굴이 절대 없다.** 눈·눈썹·코·입·표정 전부 금지 — 머리는 매끈한 흰 구. 마스코트 탈 머리도 얼굴 없이. (사용자 확정 2026-11-03)
  - Veo 는 「놀란다·깨닫는다·고민한다」 같은 감정 단어를 주면 얼굴을 그려 넣는다. 감정은 **몸짓으로만** 쓰고, 영상 프롬프트마다 아래 문장을 넣는다:
    `IMPORTANT: every head is a perfectly smooth blank white sphere with absolutely no face: no eyes, no eyebrows, no nose, no mouth, no facial expression at any moment; show emotion only through body posture and gestures.`
  - 컷을 받으면 컷당 6프레임을 뽑아 얼굴이 생기지 않았는지 확인한다.
- **내레이션은 10% 빠르게** (목소리 톤 유지, `rubberband` 필터). 편집 스크립트의 `TEMPO=1.1` 기본값.

- **main 에 직접 푸시하지 않는다.** 이 작업은 `docs/발표준비` 브랜치에서만 한다. (`docs/브랜치-작업규칙.md` 참고)
- 영상·음성 같은 큰 파일은 git 에 넣지 않는다. URL 과 job ID 로 기록한다.
- 생성은 크레딧이 든다. 같은 생성 호출을 재시도로 반복하지 말고, 컷 확정 전엔 저가 모델·저해상도로 먼저 본다.
- API 키 같은 비밀값은 채팅·파일·커밋에 남기지 않는다.
