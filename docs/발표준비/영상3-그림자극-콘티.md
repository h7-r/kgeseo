# 영상 3 — 함 속 그림자극 「그날 밤」 콘티

> 레퍼런스(`main` 브랜치): `naju01/src/puzzles/ridge/shadowPlay.ts`(컷·시각) · `shadowPlayArt.ts`(그림 재료) · `BoxOpening.tsx`(함 열기 → 재생 → 효과음·흔들림)
> 지금 게임은 이 영상을 **코드로 그린다**(캔버스 1024×576, 초당 30장). 이 콘티는 같은 장면을 **우리 방식(AI 이미지 → Veo 컷 → 로컬 편집)** 으로 만든 영상판이다.
> 시각·컷 순서·효과음 시점은 코드와 **똑같이** 맞춘다 → 나중에 게임에 영상 파일로 바꿔 끼워도 효과음(`SHADOW_PLAY_CUES`)이 그대로 맞는다.

## 지켜야 할 것

- **누가 밀었다거나, 구렁이가 된 장면은 보여 주지 않는다.** 미끄러짐의 원인은 소똥, 셋은 「골탕만 먹일 셈」이었고 손은 **늦게** 뻗는다.
- 대사·글자 없음. 효과음은 영상에 넣지 않는다(게임이 시각에 맞춰 재생). 생성할 때 **오디오 끔**.
- 얼굴은 그리지 않는다 — 전원 **먹빛 실루엣**, 달빛 쪽 윤곽만 얇게 빛난다. 6컷의 옆얼굴도 이목구비 없는 실루엣 윤곽선 + 눈물 한 방울만.

## 만드는 방식

1. **화풍 기준 이미지 1장** — 위 화풍표대로 1컷 장면을 먼저 만들고, 나머지 컷 이미지는 전부 이 이미지를 레퍼런스로 넣어 그림자극 톤을 통일한다.
2. **컷별 시작 이미지 9장** (`gpt_image_2_5`, 16:9). 매 프롬프트에 「flat ink-black silhouettes, shadow puppet theatre, thin moonlight rim light, no facial features, no text」.
3. **컷별 영상 9개** — Veo 3.1 Lite **4초, 오디오 끔**. 컷이 0.55~3.7초로 짧으니 편집에서 필요한 구간만 잘라 쓴다(빠르게 돌리지 않고 자르는 쪽 우선).
4. **편집(로컬 ffmpeg)** — 시각표대로 이어 붙이고, 컷 전환 어둡게(0.06초)·처음 0.6초 밝아짐·위아래 띠·색 보정·입자를 입힌다. 1024×576 · 30fps 로 뽑고, 확인용으로 효과음 3개를 시각에 얹은 미리보기판도 따로 만든다(게임용 본편은 무음).
