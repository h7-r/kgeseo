# 나주 동행 NPC — 상황별 대사 (2026-11-06)

> `node naju01/tools/export-npc-lines.mjs` 가 `naju01/src/dialogue/lines.ts` 에서 뽑아 쓰는 문서다. 손으로 고치지 말고 원본을 고친 뒤 다시 뽑는다.

**2026-11-06 계약 v0.4.16 §9 로 상황 코드(11개)와 분류가 확정됐다. 대사 원문은 G3 승인을 기다린다.** 쿨다운 · 분량 같은 숫자만 🟡 조정 중이다.

동행이 **어떤 상황에서 어떤 말을 하는지**를 한 장에 모았다. 대사는 모두 넛지(1단계)다 — 어디를 보고 무엇을 만질지만 말하고 답은 적지 않았다.
베타는 존댓말(해요체) 한 벌이라 **존댓말만** 실었다. 반말은 보관만 한다(`docs/naju/naju-angam-01.npc-lines.draft.json`).

## 2. 걸음 대사 — 판정이 없는 걸음(서버 퍼즐이 아님)

걸음마다 내용이 달라 코드만으로는 못 고른다. 대사에 그 걸음의 대상을 붙여 `situations[].lines[]` 에 싣는다(§9).
§10-3: 걸음 도착(`STEP_ARRIVED`)에는 분위기 · 화면에 보이는 것만 두고, 도움말 성격 줄은 진전 없음(`NO_PROGRESS`) + 그 걸음의 대상으로 — 진전이 없을 때만 나온다.
`focus_object_id` 는 11/9 대응표의 Object ID 로 맞춘다. 그 전까지는 화면 쪽 ID(`focus_local_id`)로 짝지어 둔다.
`focus_local_id` 가 —인 걸음은 겨눌 대상 없이 걸어가기만 하거나(연기 · 갈라진 강 · 능선 · 틈), 대상 ID 가 퍼즐의 답을 드러내 적지 않은 것(화톳불)이다.

## 3. 퍼즐 넛지 — 퍼즐별

서버가 퍼즐로 찾아 주는 말이다. 안내판 설명 · 게임 알림이 이미 하는 말은 없다.

### P01 조개 숨구멍

| 언제 | 대사 |
| --- | --- |
| 도움말 — 무엇을 하면 된다 | 호미 자루에 새겨진 글, 읽어 봤어요? 아랑사가 조개를 찾던 셈법이 거기 적혀 있어요. |
| 도움말 — 무엇을 하면 된다 | 구멍마다 물이 솟는 횟수가 달라요. 한 구멍 앞에 서서 몇 번 숨 쉬는지 끝까지 센 다음에 파 봐요. |
| 도움말 — 무엇을 하면 된다 | 숨 쉬는 횟수가 같은 구멍은 속에 든 것도 같아요. 그러니까 조개가 나온 횟수의 구멍만 골라서 파면 돼요. |
| 진전 없이 오래 머물 때 | 제 생각엔 아무 구멍이나 파기보다, 잠깐 서서 물이 올라오는 걸 지켜보는 편이 빠를 것 같아요. |
| 틀리기를 되풀이할 때 | 근디 방금 그 구멍은 몇 번 숨 쉬었을까요? 같은 횟수의 구멍은 이제 건너뛰어도 돼요. |
| 틀리기를 되풀이할 때 | 헛판 횟수들을 빼면 남는 게 있어요. 호미 자루의 글과 맞춰 볼까요? |

## 4. 잡담 — 동행이 한동안 말이 없었을 때 먼저 거는 말

### 일반 잡담 — 어디서나

- 저는 걸을 필요가 없어서 편해요. 근디 발자국을 못 남기는 건 조금 아쉽네요.
- 아따, 서두르지 않아도 돼요. 전설은 몇백 년을 기다렸는걸요.
- 아까부터 생각했는데, 조사하는 눈빛이 꽤 그럴듯해요.
- 혹시 제가 너무 밝으면 말해 줘요. 줄일 수는 없지만요.
- 여기 안개는 왜곡 때문이에요. 사건을 풀수록 조금씩 걷힐 거예요.
- 막힐 때 저를 부르는 건 반칙이 아니에요. 저는 그러라고 있는걸요.
- 제게 손이 있었다면 같이 들었을 텐데요. 응원은 두 배로 할게요잉.
- 가끔은 한 발 물러서야 보이는 게 있어요. 멀리서 한번 둘러보는 것도 방법이에요.
- 방금 저한테 말 걸었어요? 아, 바람 소리였네요.
- 조용하면 제가 심심해져요. 그러니까 뭐라도 건드려 봐요, 저는 구경할게요.
- 잘 풀리고 있어요. 제가 보증해요. 근거는 없지만요.

### 나주 잡담 — 나루터 · 바위 아래 · 증언 능선(dock · rock · ridge)에서

한 구역에 묶이지 않아 `zone` 을 비워 뒀다 — 물속에서는 하지 않는 말이다. `zone_id` 는 줄마다 선택 필드다(§9).

- 이 마을 사람들은 다 어디로 갔을까요. 물건들만 그날 밤 그대로네요.
- 아랑사와 아비사 이야기, 저는 끝을 알아요. 근디 말하면 재미없겠죠.
- 아따, 강바람이 좋네요. 저는 흔들리지 않지만 기분은 내 볼게요.

### [F] 보기 「여기서 뭘 해야 해요?」의 대답 — 안내판도 첫 설명 대사도 없는 목표

안내판이 있는 목표는 안내판 설명으로, 첫 설명 대사가 있는 목표는 그 대사로 답한다. 둘 다 없는 목표만 여기서 무엇을 하는 곳인지 한 줄로 말한다 — 푸는 법은 「힌트를 주세요」가 맡는다.

| 목표 | 문구 |
| --- | --- |
| `S1_SMOKE` 연기 화살표 | 연기가 화살표로 모였어요. 그 화살표를 따라가는 게 지금 할 일이에요. |
| `P05` 돌탑과 마법진 | 소반 둘레의 자리마다 돌탑을 세우는 곳이에요. 돌탑마다 제자리가 따로 있어요. |
| `S2_OFFER` 제물 올리기 | 소반에 제물을 올리는 곳이에요. 올릴 것은 우리가 지나온 길에서 챙긴 것들이에요. |
| `S2_ENTER` 갈라진 강 | 강물이 갈라져 강바닥에 길이 났어요. 그 길로 들어가는 게 지금 할 일이에요. |
| `S3_SCALE` 눈물 자국 | 돌판에 눈물 모양 자국이 패어 있어요. 그 자국에 꼭 맞는 것을 채우는 곳이에요. |
