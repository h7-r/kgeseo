# 나주 동행 NPC — 상황별 대사 초안 (2026-11-06)

동행이 **어떤 상황에서 어떤 말을 하는지**를 한 장에 모았다. 대사는 승인 전 FE 초안이고, 모두 넛지(1단계)다 — 어디를 보고 무엇을 만질지만 말하고 답(번호 · 차례 · 가락)은 적지 않았다.
말투는 두 벌이다. 처음에 플레이어에게 반말 / 존댓말을 물어 정한다. 둘 다 나주 말씨를 말끝 · 추임새에만 가볍게 얹고, 「~다 / ~습니까」로 끝나는 딱딱한 말은 쓰지 않는다.

- 원본: `naju01/src/dialogue/lines.ts` · 전체 목록(JSON): `docs/naju/naju-angam-01.npc-lines.draft.json` — 대사 354줄(말투 한 벌 기준 177개)
- 분류(계약 v0.4.16 §6): 퍼즐 넛지 93 → `puzzles[].nudges` · 상황 대사 70 → `situations` · 일반 잡담 11 + 나주 잡담 3 → `general_nudges`
- 상황 코드는 `BREATH_LOW` · `OFF_OBJECTIVE` · `ITEM_MISSING` 만 계약에 있고, 나머지는 FE 제안이다. 조사와 검토를 거친 판정안은 `docs/naju/NPC_상황분류표_1106.md`.
- `{name}` 목표 이름 · `{item}` 물건 이름 · `{left}` 남은 수 — 승인 원문이 고정 문장이면 다시 써야 하는 자리다(계약에서 정할 것).
