## 6. 서버에 넣을 값 (세진 · 나주 게시 콘텐츠)
- `server.json` 퍼즐의 대표 Object: P01 `OBJ_S1_CLAM_HOLES` · P03 `OBJ_S1_JAR_SLOTS` · P07 `OBJ_S1_CAVE_BIG_CLAM` · P09 `OBJ_S1_CAVE_RING_DOOR`(**서버 선행: P07 완료만** — 아래 참고), 비석 `OBJ_S1_CAVE_TABLET`(inspect만).
