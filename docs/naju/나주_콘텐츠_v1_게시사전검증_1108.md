## 1. 퍼즐 ID 형식 — PM · FE 전달용

- **서버 판정은 공식 ID(`P01` · `P03` · `P07` · `P09` · `P13-2` 등)를 그대로 쓸 수 있다.** `server.json`의 `puzzle_id`는 자유 문자열이고, 판정 경로(Interaction API)는 FE가 보낸 대표 Object(`target_id`)를 `client.json`의 `interaction.target_id`(= 퍼즐 ID)로 바꿔 찾는다. FE는 퍼즐 ID를 보내지 않는다(v1.1 §2와 같음).
- Hint API의 퍼즐 ID도 같은 문자열이다(`HINT_PUZZLE_IDS` 그대로).
- idmap 검증기 v0.1은 `PUZZLE_` 접두어가 아니면 **경고**(`RUNTIME_ID_PREFIX`)만 낸다. 게시를 막지 않는다.
- 과거 생성값(`PUZZLE_ANGAM_01…`)은 v1 묶음에 싣지 않는다(v1.1 §7).
