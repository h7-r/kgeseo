## 0. 한 줄
AI 기반 **2.5D 지역관광 방탈출** 콘텐츠 플랫폼. 관광·지역활성화가 목적이고 방탈출은 사람을 끌어들이는 미끼. (인공지능사관학교 최종 프로젝트 · 12월 시연)

## 1. 세계관·서사 (씬 톤/대사/연출 기준)
- **왜곡(歪曲)**: 원인불명 이상현상. 공간뿐 아니라 **기억·기록·사람의 존재까지** 지운다. 최초 왜곡 ≈ 30년 전.
- **합동수사본부**: 군·검·경·행정 합동 비공개 조직. 왜곡 조사·지역 통제·현장 조사관 투입·Case 복원·텔레포트 장치 연구. → 게임 내 **로비 = 합동수사본부 (화면 S4)**.
- **텔레포트 장치**: 고정 본체가 '출발 좌표 ↔ 왜곡영역 진입 좌표'를 임시 연결. 휴대형 귀환 단말로 복귀.
- **복원 / Anchor**: 왜곡은 정보를 지우기 전에 그 정보를 이루던 **'관계'를 뒤튼다**. 흩어진 단서·증언·사물을 교차검증(= Anchor 후보)해 모순을 풀면 왜곡영역이 안정화. **Case 결과 = 왜곡 제거가 아니라 '안정화'.**
- **주인공 강도윤**(`char-doyun`): 현장 조사관, 왜곡 저항성 높은 특이체질. 친구 한시우 소실을 복원한 경험으로 본부 합류. 플레이어 시점.
- **한시우**(`char-siwoo`): 소실 피해자 · 도윤의 감정적 출발점 · 핵심 Anchor.
- **서태준**(`char-taejun`): 선임 조사관 · 멘토 · 속내 모를 안내자 · 장기 미스터리 연결 인물.
- **본편 시작 = NAJU-01 앙암바위 왜곡 사건** (나주 영산포·영산강·앙암바위, 아랑사·아비사 설화). 도윤이 본부 브리핑 후 텔레포트로 진입하는 시점이 실제 플레이 시작점.
  - **MVP/시연 지역 = 나주** (NAJU-01 앙암바위 첫 케이스). ~~여수·순천~~은 옛 계획으로 **폐기** — 더 이상 진행하지 않음. (구 브리프 문서에 남아 있는 "여수·순천" 표기는 오래된 것.)
- 감정 톤: 영웅 서사 아님. "나만이라도 잊지 않겠다" — 기억·관계의 회복. **실패 없는 설계**(오답·조합 실패에 불이익/소모 없음).

## 2. 화면 흐름 (화면설계서 IA · WF-S0~S7)
`S0 메인(랜딩)` → `S1 계정·동의` → `S2 캐릭터 생성(조사관 등록, 남/녀)` → `S3 오프닝 시네마틱(≈60초 뉴스 몽타주·가상 방송사)` → **`S4 로비 = 합동수사본부`** → `S5 훈련실 튜토리얼` → `S6 케이스 선택·로딩·브리핑` → **`S7 케이스(방탈출)`**

**현재 코드 매핑**
- 공용 로비 / 합동수사본부 = **S4**
- 복도·음료/커피 자판기·소화전(밸브·관창·배전반 배선)·번호 자물쇠 퍼즐 = **S7 케이스 공간**
- 훈련실 = **S5**
- 기차역·기차 = 코드에 구현됨. 구 '출발 허브' 인트로용이었으나 인트로가 뉴스 몽타주로 바뀌며, 이제는 '장소 간 이동 = 시네마틱' 연출 용도로 활용 가능.
- **인트로 = S3 뉴스 몽타주 시네마틱으로 확정** (≈60초, 가상 방송사). 구 '공항/기차역 허브 → 지구본 → 수직 하강' 인트로는 **폐기** — 지구본·허브 인트로 진행 안 함.

## 3. 공통 UI/구현 규칙 (화면설계서 §3 — FE 필수 준수)
- **게이트는 서버값으로**: 케이스 진입 가부는 `GET /progress` 의 `tutorialDone` 만 본다. 화면 자체 플래그로 열지 않음(새로고침 우회 방지).
- **모달은 한 번에 하나**: ESC는 열린 모달을 먼저 닫고, 모달이 없을 때 일시정지를 연다. 모달이 열리면 타이머 정지.
- **전환 1초 이내**(세션 전환은 페이드로 로딩을 가림) · 첫 로딩 3초 · **조작 반응 100ms**.
- **오류 안내**: 네트워크 오류는 토스트 + 이벤트를 로컬에 쌓아 재전송. 진행을 막지 않는다.
- **실패 없는 설계**: 오답/조합 실패 불이익 없음, 아이템 소모 없음(단조성).
- **이벤트 전송**: 5초 배치 + 이탈 시 강제 전송. **허용 목록 18종만**.
- 조작(S4): WASD 이동(경사 판정) · 마우스 시점 상하 ±80° · Space 점프(접지 시) · **Shift 달리기**.
- **첫 클릭 전 무음**(브라우저 자동재생 정책) — 사운드 시스템이 이미 첫 입력에 오디오 컨텍스트를 깨우는 방식으로 반영.

## 4. 상호작용·퍼즐 가드레일
- **공용 인터랙션 8종 화이트리스트**: `observe`(관찰) · `collect`(획득) · `compare`(비교) · `rotate`(회전) · `align`(겹치기) · `connect`(연결) · `sequence`(순서) · `input_code`(암호). Scene은 이 ID만 참조, 임의 추가 금지(추가 시 프론트 검토 후 카탈로그 등록).
- **SceneInventory**: 씬에 실제 존재하는 물건만 퍼즐 재료. **장식 전용(dressing_only)·미등록 물건은 퍼즐에 못 씀.**
- 퍼즐은 이야기의 정보 공개·관계 복원에 직접 기여.
- **FE 구현 현황**: 로비 물건 집기/놓기, 음료·커피 자판기(동전 투입·반환·캔/컵 배출·힌트종이·VALVE 퍼즐), 소화전(개폐 밸브·관창 노즐·배전반 3색 배선), 번호 자물쇠 — 상호작용 + **효과음 배선 완료**.

## 5. Case 진행 흐름 (10단계)
왜곡 감지·본부 브리핑 → 텔레포트 진입 → 현장 인물·초기 오해 → 공간 탐색·증언/기록/사물 조사 → 단서 수집·Anchor 식별·교차검증·모순 발견 → 1차 진실/반전 → 미해결 관계 추적 → 진실·감정 복원 → 왜곡 안정화·엔딩 → 귀환 단말로 본부 복귀·장기 미스터리 단서 축적.

## 6. 화풍·기술 스택
- **2.5D**: 3D 무대에 2D 이미지 배치(디오라마/점앤클릭), 좌우 사이드뷰 워크. 풀3D 아님(지구본·봉인 전환만 3D).
- 셀 셰이딩(`MeshToonMaterial`) + 외곽선 + 그레인 + 따뜻·차분한 색(Messenger/abeto 톤 차용). 후처리 한 겹으로 AI배경·실사·3D를 한 세계로 묶음.
- **React + Three.js/R3F + drei + GSAP + zustand + Vite.** 에셋: Meshy(3D 물건) · Firefly(배경 아트) · Skybox AI(360).
