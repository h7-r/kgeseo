# 에셋/바위 — Meshy 가 **형태째** 만든 바위를 놓는 곳

여기에 `.glb` 를 넣으면 씬이 자동으로 찾는다(`src/바위에셋.js`).
Leva 의 `바위에셋` 을 켜고 `바위폭·바위X·바위Z·바위Y·바위회전` 으로 자리를 맞춘다.

## 왜 여기가 따로 있나

Meshy 의 **리텍스처는 재질만** 입힌다 — 우리가 넘긴 삼각형을 한 개도 안 바꾼다
(실측: 92,910 → 92,910). 그러니 「프롬프트로 바위 모양을 둥글게」는 원리상 안 된다.
형태를 바꾸려면 **Image-to-3D / Text-to-3D 로 새 덩어리를 만들어야** 한다.
그렇게 만든 것을 여기 넣는다.

## 판정과의 관계

이 바위는 **그림 전용**이다. 걷는 높이는 계속 `지형.js` 의 배터를 쓴다.
그래야 도면 대조(±0.5 m)와 실측 하네스(`구멍2` · `걷기2` · `맞춤`)가 살아 있다.

## 크기

Meshy 출력은 크기가 제멋대로다. `에셋.js` 의 `실치수맞춤` 이 **가로 실치수(m)** 로
못 박아 준다. 절벽 폭이 22 m 이므로 `바위폭` 기본값도 22 다.
