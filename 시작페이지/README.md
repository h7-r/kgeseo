# 시작페이지

> **이 화면들은 「창 폭 기준」이다.** 피그마 원본이 1920 고정 좌표 디자인이라,
> 1920 으로 정확히 짜고 **창 폭에 맞춰 통째로 축소**한다. 창을 좁히면 글자도 같이
> 작아진다 — 기기별 반응형이 아니다. 개발 중에는 오른쪽 아래에 지금 배율이 표시된다
> (빌드 결과물에는 안 들어간다).


게임에 들어가기 **전에** 뜨는 웹페이지. 피그마 「메인 (Main)」 프레임(3:3, 1920 × 9020)을
그대로 옮긴 것이다.

## 실행

```bash
npx vite 시작페이지        # → http://localhost:5175
npx vite build 시작페이지  # 빌드
```

저장소 뿌리의 `package.json` 하나만 설치돼 있으면 된다. 여긴 자체 `package.json` 이
없고 뿌리의 `node_modules` 를 그대로 쓴다. (naju01 과 같은 방식)

포트는 못 박혀 있다 — 본편 5173 · naju01 5174 · 시작페이지 **5175**.

## 어떻게 짜여 있나

원본이 오토레이아웃이 아니라 **1920 고정 좌표** 디자인이다. 반응형으로 다시 짜면
"그대로" 가 깨지므로, 1920 으로 정확히 짜고 창 폭에 맞춰 **통째로 축소**한다
(`무대.jsx`). 어떤 창 크기에서도 비율이 안 틀어진다.

`src/데이터/` 의 파일들은 **손으로 옮겨 적은 게 아니라 피그마 생성 코드에서 뽑아낸
것**이다. 변형(variant) 코드의 조건식(is / is1)을 풀어 활성 탭 쪽만 남겼다.
글을 고칠 일이 생기면 피그마를 고치고 다시 뽑는 게 맞다.

`src/구간/` 은 화면 조각, `src/화면/` 은 주소 하나에 대응하는 페이지다.

## 에셋

`node 시작페이지/에셋색인만들기.mjs` 가 `src/에셋.js` 를 만든다.
**그림을 새로 내려받은 다음에는 반드시 돌려야 한다** — 안 돌리면 코드가
`에셋.imgXxx` 를 undefined 로 읽어 깨진 이미지가 뜬다(실제로 한 번 겪었다).
`--검사` 를 붙이면 어긋났을 때 실패한다.

## 고칠 때 주의할 것 두 가지

**1. 칠하는 순서를 바꾸지 마라.** `시작화면.jsx` 의 컴포넌트 나열 순서가 곧 피그마
레이어 순서다. 특히 `<큰빛 />` 과 `<가입폼 />` 은 반드시 맨 뒤여야 한다. 앞으로
옮기면 렌즈 모양(21:1114)이 빛 위로 떠올라 **검은 덩어리**처럼 보인다.

**2. `word-break: break-word` 를 빼지 마라.** 피그마 텍스트 노드는 거의 전부 이걸
달고 나온다. 없으면 "50+" 같은 글자가 칸(97px)을 넘겨도 안 쪼개져서 원본과 줄 수가
달라진다. `시작화면.jsx` 의 무대 칸에서 한 번에 걸어 뒀다.

## 글꼴

피그마 변수 기준 — Bebas Neue(제목) · IBM Plex Mono(라벨·로고) · Inter(본문) ·
Syncopate(폼 제목). 전부 Google Fonts 에서 받는다.

한글은 피그마 변수에 안 잡혀 있다. 지금은 **Pretendard** 로 두었다. 원본에서 쓰는
한글 글꼴이 확인되면 `토큰.css` 의 `--글꼴-한글` 한 줄만 바꾸면 전부 따라온다.

## 게임과의 관계

**아직 연결돼 있지 않다.** 일부러 그렇게 뒀다. 본편 `src/` 의 어떤 파일도 import 하지
않고 `App.jsx` · 라우터도 건드리지 않는다. 붙일 때는 이 폴더를 본편 라우트로 옮기고
「플레이하기」 · 「지금 시작하기」 에 라우팅만 연결하면 된다.

## 자산 두는 곳

| 무엇 | 어디 | 어떻게 쓰나 |
| --- | --- | --- |
| 피그마에서 뽑은 이미지 | `시작페이지/에셋/` | `src/에셋.js` 를 통해 import |
| 이 페이지 전용 정적 파일 | `시작페이지/public/` | `/favicon.svg` 처럼 절대경로 |

**뿌리 `public/` 을 publicDir 로 공유하지 않는다.** publicDir 안의 파일은 쓰든 안 쓰든
통째로 복사되는데, 거기엔 게임용 GLB 모델과 텍스처가 있어 이 페이지 빌드가 13MB 가
돼 버린다. 공용 자산이 필요하면 상대경로로 가리킨다:

```css
src: url("../../public/fonts/eonggeongkwi.woff2") format("woff2");
```

### 장식은 클릭을 통과시킨다

배경 글로우·꺾쇠·조준선에는 `pointerEvents: "none"` 이 걸려 있다.
안 걸면 큰 글로우(12:2336 등)가 단추 위를 덮어 **눌러도 아무 일이 안 일어난다**
(실제로 「모든 지역 보기」가 그래서 안 눌렸다). 장식 층을 새로 넣을 때도 반드시 달 것.

## 아직 안 움직이는 것 — **막아 두었다**

피그마에 다음 화면이 없는 것들이다. 손가락 커서를 떼고 `title` 로 이유를 달아
「눌리는 줄 알았는데 안 눌린다」가 되지 않게 했다 (`공통.js` 의 `막음` · `막음안내`).

- 메인 지역 카드 좌우 화살표 — 넘길 카드가 3장뿐
- 영상 페이지 쪽번호(1~5)와 화살표 — 2쪽 이후 영상이 없음
- 푸터의 탐험·지역 맵·퀘스트·보상 — 대응 페이지 없음
- 요금제 「구독하기」 — 갈 화면이 없음
- 인증·가입폼의 소셜 아이콘, 메인 가입폼 「모험 시작하기」
- 고객센터 「문의 접수하기」 — 보낼 곳이 없음
- 마이페이지 설정의 「변경하기」·「활성화」 같은 값
- 게임소개 쪽번호 6번 — 여섯 번째 탭이 없어 흐리게 둠

화면이 생기면 그 자리에 `onClick` 만 달면 된다.

## 부가 기능

### 유효성 검사 (`src/유효성.js`)

로그인·회원가입·비밀번호 재설정·1:1 문의·메인 가입폼에 붙어 있다.

- 이메일 형식, 비밀번호 8자 이상, 비밀번호 확인 일치, 필수 입력, 약관 동의, 인증코드 6자리, 문의 내용 10자 이상
- **단추를 누른 뒤부터** 검사한다. 타이핑 도중에 빨간 글씨가 뜨면 아직 다 적지도 않았는데 혼나는 느낌이 든다
- 한 번 혼난 뒤에는 고치는 즉시 오류가 풀린다
- 오류 글은 칸 **아래에 절대 위치로 띄운다** — 칸 높이가 늘어나 배치가 밀리지 않도록
- 회원가입 비밀번호 세기 막대 3칸이 실제 세기를 따라간다

### 호버 (`index.css`)

피그마에 호버 상태가 없어서, 원본을 해치지 않는 선에서 **밝기와 1px 이동**만 준다.
`.단추` · `.링크` · `.탭` · `.카드` · `.줄` 네 종류. 막아 둔 것에는 안 붙인다.

### 구독 플랜 강조

가운데(PREMIUM)가 기본으로 **뒤에서 빛나고** 제 크기이며, 양옆은 `scale(0.955)` 로
조금 작다. 마우스를 올리면 그 카드로 강조가 **부드럽게 옮겨 간다**(0.26s).

### 푸터는 항상 맨 아래

무대가 **맨 아래 요소까지의 높이를 재서** 그만큼만 쓴다. 숫자로 적어 두었을 때는
메인 198px · 인증 87px · 404 125px 이 푸터 아래에 비어 있었다
(피그마 메인 프레임이 9020 인데 푸터는 8822 에서 끝난다).
탭을 바꿔 길이가 달라져도 ResizeObserver 가 다시 잰다.
