# 닉네임 판정 검사

닉네임·금칙어 판정(`website/src/lib/nicknamePolicy.ts` · `koreanText.ts`, 목록 `shared/nickname-policy.json`)이
**막아야 할 것을 다 막는지**, **막으면 안 되는 것을 얼마나 막는지**, **백엔드와 어디서 어긋나는지**를 숫자로 다시 낸다.
PR 설명에 적은 숫자는 모두 이 도구로 낸 것이다.

```bash
npm run check:nickname                        # 세 검사 모두(약 1분 10초)
npm run check:nickname -- --parity            # ① 백엔드 비교만
npm run check:nickname -- --variants          # ② 막아야 할 변형만
npm run check:nickname -- --variants --seed 7 #    다른 시드로
npm run check:nickname -- --false-positives   # ③ 오탐만
```

콘솔에 요약을 찍고, 목록까지 담은 결과를 `tools/nickname-policy/.cache/report.json` 에 남긴다.

```
tools/nickname-policy/
  check.mjs            실행 — 판정 코드를 묶고(vite·rolldown → .cache/judge.mjs) 고른 검사를 돌린다
  parity.mjs           ① 입력 묶음 생성 → 화면 판정 → backend.py → 비교
  backend.py           ① 백엔드 판정기를 importlib 로 그대로 불러 판정(백엔드 코드는 읽기만)
  variants.mjs         ② 금칙어마다 우회 표기를 계산으로 만들어 막히는지
  false-positives.mjs  ③ 이름·정상 문장·외부 말뭉치에서 걸리는 것
  common.mjs           경로·규칙 파일·고정 시드 난수
  .cache/              묶은 판정 코드·받은 말뭉치·결과(깃에 올리지 않는다)
```

## 준비

- 루트에서 `npm install` 만 하면 된다. 따로 받을 패키지는 없다(번들은 루트의 vite 를 쓴다).
- ① 은 **Python 3.9 이상**이 필요하다(macOS 기본 `python3` 3.9 로 돈다). FastAPI 같은 백엔드 의존성은 필요 없다 —
  `backend/app/services/nickname_policy.py` · `registration_input_policy.py` 두 파일만 불러온다.
- ③ 의 외부 말뭉치는 처음 실행할 때 인터넷에서 받아 `.cache/` 에 둔다. 받지 못하면(오프라인) 그 부분만 건너뛰고 알린다.

## 세 검사

### ① 백엔드 비교 (`--parity`)

닉네임 1만 3천여 개(금칙어·예약어·예외 낱말과 그 변형 + 무작위 4,000개, 고정 시드),
비밀번호 1,752개, 이메일 862개를 화면 판정과 백엔드 판정에 똑같이 넣는다.

- **서버는 막는데 화면은 통과** — 화면을 믿고 제출했다가 서버에서 거절당하는 경우. 0 이어야 한다.
- 화면만 막음 — 화면 목록이 서버 목록보다 넓은 만큼. 서버가 아직 자체 목록을 쓰므로 많은 것이 정상이다.
- 이메일은 입력 그대로와, 화면이 실제로 보내는 값(앞뒤 공백을 뗀 값) 두 가지로 비교한다.

지금 백엔드는 `shared/nickname-policy.json` 을 읽지 않고 `nickname_policy.py` 의 자체 목록으로 따로 검사한다.
이 JSON 으로 통합하면(후속 작업, JSON 의 `matching.$steps` 를 따르면 같은 판정이 난다) ① 의 「화면만 막음」이 0 에 가까워진다.

### ② 막아야 할 변형 (`--variants`)

모든 금칙어 기본형과 `compose` 규칙을 펼친 조합형마다 우회 표기를 만든다(고정 시드 99).

| 변형        | 예                                      |
| ----------- | --------------------------------------- |
| 끼움        | 시1@3발, 시 발, 시_발 — 숫자·기호 1~5개 |
| 늘이기      | 시이이잉발, 시바아아알, 시ㅡ발          |
| 된소리·모음 | 씨빨, 쒸발, 개세끼                      |
| 자판 영문   | tlqkf, TLQKF                            |
| 앞말 조합   | 존나시발야                              |
| 영문        | FUCK, fuuuck, xxfuck99                  |

자유 글(`findProfanity`)과 닉네임(`findNicknameProblem`) 두 판정 모두 100% 막혀야 한다.
닉네임은 형식 단계(특수문자·자모·길이)에서 막혀도 막힌 것으로 세지만, 기호가 없는 것은 금칙어 판정으로 막혀야 한다.

### ③ 오탐 (`--false-positives`)

- **이름** — 성 100개 × 이름 130여 개(금칙어와 한 끗 차이인 미진·병철·신발·세기·문재 등 포함). 사용자 결정으로 막아 둔
  염병철·염병수·염병진 말고 걸리는 것이 있으면 「새 오탐」으로 따로 보인다.
- **정상 문장** — 한 끗 차이 함정 문장 31개 + 자막 낱말 4~8개를 띄어 이은 문장 5,000개.
- **외부 말뭉치** — 자막 빈도 낱말 5만(한국어·영어)과 그 둘을 이어 붙인 닉네임형, 욕설 여부가 표시된 문장.
  낱말 목록에는 원래 욕도 들어 있어, 걸린 목록(`report.json`)을 사람이 보고 판단한다.
