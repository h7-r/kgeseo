# P5 게임 연동 준비 — 작업 목록과 미결정 계약

> 작성 2026-10-26 · 상태 **정리만 함** — backend · frontend · 실제 게임 콘텐츠는 수정하지 않았다.
> 우선 후보: **A군 선택형 발화(승인 문장 + 고정 목록의 여는 말 · 맺는 말) + 승인 템플릿 대체**. 사람 평가(`docs/10`) 전에는 운영 기본 방식으로 확정하지 않는다.

## 1. 연동 구조 (후보)

```
FE(플레이어 행동 · 포커스 · 보이는 대상 · 도움 요청)
  → BE 세션 API ─→ NPC 판단층(P3 · 개입 여부 · check_in / nudge / hint)
                └→ NPC 발화층(P4 · 서버 안에서만): 사전 조건 → 근거(same_level) → 생성(템플릿 / A군) → 검증 → 대체
  ← NpcUtterance(말풍선 / 대화창 · kind · 문장)
```

- **판정 · 상태는 backend 가 한다.** 정답 판정 · 퍼즐 완료 · 정적 Hint API 는 바꾸지 않는다. NPC 는 읽기만 한다.
- 정답 · 별칭 · 금지어 · 검증기는 서버에만 있다. 클라이언트에는 최종 문장만 간다.

## 3. 미결정 계약

| 계약 | 필요한 것 | 현재 |
|---|---|---|
| FE → BE 플레이 신호 | 현재 구역 · 포커스(퍼즐 / 오브젝트) · **FE 가 확인한 보이는 대상**(clarify 이름 · #35) · 세션 시작 / 일시정지 / 종료(#19) · 도움 요청 버튼 · 대상 선택 | 없음 |
| 발화 요청 | `NpcContext`(있음) + 계획(유형 · 시작 주체 · 대상 퍼즐 · 플레이어 메시지) | 계약 초안만(P1 · P4-A) |
| 발화 응답 | `NpcUtterance`(있음) — 표시 방식(말풍선 / 대화창) · kind · 문장 · 대체 여부 | 계약 있음 · FE 표시 규칙 없음 |
| 시간 초과 의미 | 몇 초 뒤 템플릿 고정인가 · FE 가 기다리는가 | 미정 |
| LLM 허용 | 세션 · 사용자별 `allow_llm` · 외부 API 사용 동의 · 지역 처리 | 미정(실험은 가상 사건만 외부 전송) |
| 비용 · 호출 상한 | 세션 · 일 단위 상한 · 넘으면 템플릿 | 미정 |
| 원문 로그 | 보존 · 열람 · 삭제(#39) | 실험은 로컬 7일 수동 |
| 콘텐츠 승인 | NPC 힌트 단계 · 공개 조건 · 승인 기록(#31 · #49) | 테스트 견본만 |
